# Decodelabs-Internship-Project-2-Exploratory-Data-Analysis-EDA

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on an e-commerce dataset using Microsoft Excel.

The main objective is to clean, validate, organize, and analyze the dataset to identify patterns, trends, and useful business insights.

The project demonstrates the complete workflow from **raw data → data cleaning → validation → exploratory analysis → insights**.

---

## 📊 Dataset Overview

The dataset contains **1,200 order records** with information related to customers, products, orders, payments, shipping, and sales.

### Key Columns

* **OrderID** – Unique identifier for each order
* **Date** – Order date
* **CustomerID** – Customer identifier
* **Product** – Product purchased
* **Quantity** – Quantity ordered
* **UnitPrice** – Price per unit
* **ShippingAddress** – Customer shipping address
* **PaymentMethod** – Payment method used
* **OrderStatus** – Current status of the order
* **TrackingNumber** – Shipment tracking identifier
* **ItemsInCart** – Number of items in the cart
* **CouponCode** – Coupon applied to the order
* **ReferralSource** – Source through which the customer arrived
* **TotalPrice** – Total order value

---

## 🧹 Data Cleaning & Preparation

The dataset was cleaned and prepared before performing the analysis.

### Main Cleaning Tasks

* Handled missing values in the dataset
* Replaced missing coupon codes with **"No Coupon"**
* Standardized date formats
* Standardized numerical values
* Validated unique identifiers
* Checked for duplicate Order IDs
* Checked for duplicate records
* Verified data consistency
* Documented changes in the **Change Log**

---

## 🔎 Exploratory Data Analysis

The cleaned dataset was analyzed to understand:

* Customer and order activity
* Product demand
* Average quantity per order
* Average order value
* Referral-source performance
* Distribution of orders across products

### Key Findings

* **Total Records:** 1,200
* **Average Quantity per Order:** 2.95
* **Average Order Value:** 1,053.97
* **Highest-ordered Product:** Printer
* **Lowest-ordered Product:** Phone
* **Top Referral Source:** Instagram

These findings provide an initial understanding of purchasing behavior and product performance.
